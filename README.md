# Mausam

A responsive weather dashboard for personalized daily planning. Weather and geocoding are powered by Open-Meteo, so no API key is required.

## Run locally

1. Install Node.js 18 or newer.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Included

- Real current, hourly, and seven-day weather data
- Open-Meteo city and country search with suggestions
- Browser location permission with manual-search fallback
- Local preferences and saved locations
- Responsive sidebar, mobile bottom navigation, and touch-friendly forecast scrollers
- Dedicated Health, Fitness, Beach, Travel, Family, Agriculture, Commute, and Events views
- Explicit unavailable states for data Open-Meteo does not provide, including marine, soil sensor, pollen, and live traffic data
- Loading, retry, empty, and location error states
